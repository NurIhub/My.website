# Отчет по практической работе: Создание простого веб-сайта

## Информация о проекте
* **Тема сайта:** Персональный сайт-визитка начинающего разработчика.
* **Общая тематика (тип сайта):** Информационный сайт / Сайт-визитка.

## Описание проделанной работы
В ходе выполнения задания был разработан простой статичный сайт, состоящий из одной страницы. 

**Что было сделано:**
1. Разработана логическая структура документа в файле `index.html` с использованием семантических тегов (`<header>`, `<main>`, `<section>`, `<footer>`).
2. Настроен внешний вид элементов в файле `style.css`: задана цветовая гамма, шрифты, отступы и базовое оформление блоков для удобного чтения.
3. Организована правильная файловая структура проекта для последующей запаковки в архив.
